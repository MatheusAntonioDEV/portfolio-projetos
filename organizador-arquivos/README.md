# Sistema de Automação e Organização de Arquivos

Script desenvolvido em Python focado na automação de rotinas operacionais e organização de fluxos de trabalho através da manipulação do sistema de ficheiros.

## 🚀 Funcionalidades
- Leitura dinâmica de diretórios de entrada (ex: pasta de Downloads).
- Identificação e classificação inteligente de ficheiros por extensão (`.pdf`, `.png`, `.xlsx`, etc.).
- Movimentação automatizada para diretórios de destino estruturados.
- Otimização do fluxo de trabalho diário ao eliminar a triagem manual.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Módulos Nativos:** `os`, `shutil`

## ⚙️ Como Executar
1. Clone este repositório ou descarregue o ficheiro `organizador.py`.
2. Abra o terminal na pasta onde o script está localizado.
3. Execute o comando:
   ```bash
   python organizador.py
